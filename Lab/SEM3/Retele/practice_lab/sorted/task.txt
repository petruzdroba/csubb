1. The client connects to the server using TCP on a known port.
2. The client sends a list of integers as a space-separated string (e.g., "5 9 2 3 1").
3. The server receives this data, parses it, and sorts the integers.
4. The server opens a UDP socket on a free port.
5. The server sends the UDP port number back to the client over the TCP connection.
6. The client closes the TCP connection and listens on the provided UDP port.
7. The server sends the sorted integers back to the client over UDP in the format: "Sorted result: 1 2 3 5 9".
8. The client prints the result and closes.

Example Flow:
TCP:
  Client -> Server: "5 9 2 3 1"
  Server -> Client: "UDP_PORT=49215"

UDP:
  Server -> Client: "Sorted result: 1 2 3 5 9"
